## 2. The platform (4 min)
1. Architecture: Master Doc §4.1 diagram (CloudFront → k3s on one Graviton node; Lambda → SQS → workers; Bedrock).

   **Promote** workflow (required approval) → prod. Show the `production` environment approval.
3. Grafana (port-forward over SSM): *Docify Overview* (RPS, p95, errors), *Workers & Jobs* (queue, KEDA),

4. Scaling numbers: k6 50 VUs × 10 min → 30,668 requests, 0 errors, p95 107 ms; HPA 2→3→2;

## 3. When things break (2 min) — `docs/incidents/`

- Postgres stopped 60 s → 503s, self-healed 6 s after DB back; Argo selfHeal even "fixed" the first attempt.
- Bad release → migrate hook blocked it, 0 downtime, `git revert` rollback.
- Restore drill: S3 backup → verified DB in 20 s.
